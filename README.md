# Artomovsk
Назначение проекта
Учебный веб-сайт, посвящённый городу Артёмовску (Бахмуту) — его истории, инфраструктуре, культуре и культурному наследию.

Использованные технологии
HTML5
Семантическая разметка: <header>, <nav>, <section>, <article>, <footer>.
Структурирование контента: <h1>, <h2>, <h3>, <p>, <span>, <table>, <tr>, <th>, <td>.
Мультимедиа: <img> для фотогалереи, <iframe> для встраивания карты.
Формы и валидация: <form>, <label>, <input>, <textarea>, <button>.
Атрибуты валидации: required, minlength, maxlength, type="email".
Мета-теги: <meta charset>, <meta name="viewport"> для адаптивности.

CSS3
Сброс стилей: универсальный селектор *.
Раскладка: display: flex (шапка, меню, форма, группы полей), display: grid (карточки новостей).
Позиционирование: position: sticky (прилипающее меню).
Оформление: background, color, border, border-radius, box-shadow, padding, margin.
Анимации: transition для плавных переходов при наведении и фокусе.
Псевдоклассы: :hover, :active, :focus, :focus-visible, :valid, :invalid, :not(), :placeholder-shown.
Комбинаторы: потомок ( ), родственный (~).
Каскад и наследование: переопределение стилей от общих к частным.


Валидация формы
HTML5-атрибуты: required, type="email", minlength, maxlength.
CSS-псевдоклассы: :valid, :invalid, :not(:placeholder-shown).
Без JavaScript — проверка полей и показ ошибок реализованы только разметкой и стилями.

Структура страниц
Файлы HTML
main.html	Главная страница: описание города, фотогалерея, новости, форма обратной связи
history.html	История города — таблица ключевых событий с датами и значением
Infrastructure.html	Инфраструктура: география, карта, административное деление, транспорт
cult.html	Культура и искусство: театры, музеи, галереи, известные деятели
about.html	О разработчике: фото, информация о студенте, навыки с прогресс-барами, форма обратной связи
form.html	Отдельный файл с разметкой формы

Файлы CSS
style_form.css	Стили формы обратной связи: карточка, поля, валидация, кнопка

Чтобы запустить сайт локально:
1) установите Себе на компьютер Web_lab1.rar;
2) распакуйте содержимое
3) запустите main.html
